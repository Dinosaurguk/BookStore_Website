Веб-приложение книжного магазина на Flask с авторизацией пользователей и интеграцией с СУБД MS Access.

# BookStore — Веб-платформа для управления книжным фондом и онлайн-коммерции

Стильное веб-приложение для интернет-магазина или цифровой библиотеки с полноценной интеграцией с базой данных, системой динамической загрузки контента и пользовательской авторизацией.

## 🚀 Основной функционал

- **Система авторизации и аутентификации:** Полноценная регистрация пользователей, сессии (`flask.session`), валидация данных на стороне сервера и привязка личных аккаунтов.
- **Динамический каталог (CRUD):** Возможность добавления новых томов в архив фондов в реальном времени через веб-интерфейс.
- **Интеллектуальная обработка медиа-ресурсов:** Автоматический подъем обложек книг из директории `book_images`. При отсутствии изображения система автоматически обрабатывает исключение и устанавливает стандартизированную заглушку (placeholder), сохраняя целостность UI.
- **Интеграция с СУБД:** Логика приложения полностью связана с реляционной базой данных (MS Access) через ODBC-драйвер для надежного хранения информации о книгах, пользователях и сессиях.

## 🛠️ Технологический стек

- **Backend / Logic:** Python 3 (Flask)
- **Database:** MS Access (библиотека `pyodbc`)
- **Frontend:** HTML5 (Jinja2 Templates), CSS3 (Кастомный UI в темных тонах), JavaScript
- **Архитектура:** Модель клиент-серверного взаимодействия с серверной валидацией форм и управлением сессиями пользователей.

## 📂 Структура проекта

* `server.py` — Главный серверный файл приложения (бэкенд-логика, маршрутизация Flask, сессии и SQL-запросы к БД).
* `database.accdb` — Реляционная база данных Microsoft Access (хранение учетных записей пользователей и каталога книг).
* `templates/` — Шаблоны HTML-страниц с динамическим рендерингом данных через Jinja2.
* `book_images/` — Локальное хранилище для обложек книг (включая дефолтную заглушку).
* `style.css` — Стили оформления веб-интерфейса (адаптивный дизайн).
* `migrate_passwords.txt` — Экспериментальный скрипт для миграции базы данных и внедрения хэширования паролей.

## 🗂️ Как запустить проект локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Dinosaurguk/BookStore_Website
   ```
2. Установите необходимые компоненты (Flask, pyodbc):
   ```bash
   pip install flask pyodbc
   ```
3. Убедитесь, что файл базы данных `database.accdb` находится в корневом каталоге проекта.
4. Запустите сервер:
   ```bash
   python server.py
   ```
5. Откройте в браузере: `http://127.0.0.1:5000`
